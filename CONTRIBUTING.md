# Contributing

1. Open or identify an issue before starting work.
2. Create a focused branch from `develop`.
3. Keep commits atomic and explain user impact.
4. Open a pull request into `develop` with the issue reference and screenshots for UI changes.
5. Do not include secrets, generated credentials, or unrelated refactors.

Drips recognition is determined by the relevant program and maintainers; a merge is not a guarantee of points or funding.
